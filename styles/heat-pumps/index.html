How an install goes

Most homes are done in one day. Here is how it runs.

  1. 1

    Look and measure

    Ange visits, checks the room and where the units will go. Free, about 30 minutes.

  2. 2

    Written price

    The size, the model and the fitting, set out in writing.

  3. 3

    Fit in a day

    Indoor unit on the wall, outdoor unit on a stand, pipes run and sealed.

  4. 4

    Test and show

    Heating and cooling tested, then the remote explained to you.

Heat pumps run cheapest when set to one steady temperature and left on, so Ange sets a timer with you rather than leaving it to guess.
